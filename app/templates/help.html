Help

This page explains how to use the Personal Task Tracker.

Getting Started

  1. Create an account with a username, email address, and password of at least 8 characters.
  2. Log in to reach your personal dashboard.
  3. Add tasks with the Add Task button. A title is required; a description is optional.
  4. Update tasks with the Edit button, or use Mark Complete and Mark Incomplete to track progress.
  5. Delete tasks with the Delete button. You will be asked to confirm before anything is removed.
  6. Log out using the button in the navigation bar to end your session.
