About the Task Tracker

The Personal Task Tracker is designed to help individuals keep their day-to-day responsibilities organized without the clutter of larger project-management tools.

Many people track tasks on sticky notes, in scattered text files, or simply in their heads. This application aims to give each user a single, private place to record what needs to be done, when it is due, and whether it has been completed.

Project Goals

  • Keep the interface clean, simple, and easy to use on any device.
  • Give each user a private list of tasks tied to their own account.
  • Store information reliably in a lightweight database.
  • Follow secure practices for handling passwords and user sessions.
Built With
  • Python 3.12
  • Flask
  • Jinja2 templates
  • SQLite
  • Bootstrap 5
